## Guidelines

### React Fundamentals
- Use functional components with hooks
- Prefer composition over inheritance
- Keep components small and focused
- Use proper component composition patterns

### Hooks Usage
- Use useState for local state
- Use useEffect for side effects with proper cleanup
- Use useContext for global state when appropriate
- Use useMemo and useCallback for optimization
- Create custom hooks for reusable logic

### TypeScript
- Use TypeScript for type safety
- Define proper prop interfaces
- Use generic components when appropriate
- Avoid any type, use proper type definitions

### State Management
- Use Context for simple global state
- Consider Zustand or Redux for complex state
- Use React Query for server state
- Keep state as close to usage as possible

### Next.js
- Use App Router for new projects
- Implement Server Components where appropriate
- Use getServerSideProps or getStaticProps appropriately
- Implement proper routing with dynamic routes
- Use API routes for backend functionality

### Performance
- Implement proper error boundaries
- Use React.memo for preventing unnecessary re-renders
- Optimize images with next/image
- Implement code splitting with dynamic imports
- Use proper loading and error states

### Accessibility
- Follow WCAG guidelines
- Use semantic HTML elements
- Implement proper ARIA attributes
- Ensure keyboard navigation
