## Guidelines

### Vue 3 Composition API
- Use <script setup> syntax
- Use ref and reactive for state
- Use computed for derived state
- Use watch and watchEffect for side effects
- Create composables for reusable logic

### Component Design
- Keep components small and focused
- Use props for parent-child communication
- Use emits for child-parent communication
- Use provide/inject for cross-component data
- Implement proper prop type validation

### TypeScript
- Use TypeScript in Vue components
- Define proper TypeScript interfaces for props
- Use generic components when appropriate
- Enable strict mode in TypeScript

### State Management
- Use Pinia for state management (Vuex 5 replacement)
- Organize stores by feature module
- Use actions for mutations
- Implement proper state persistence if needed

### Vue Router
- Use proper route configuration
- Implement navigation guards for auth, analytics
- Use lazy-loaded routes for code splitting
- Implement proper route params handling
- Use route meta fields for route metadata

### Performance
- Use v-show for conditional rendering
- Use v-if for conditional DOM elements
- Implement proper key for v-for
- Use AsyncComponent for lazy loading
- Optimize with defineAsyncComponent

### Error Handling
- Implement error boundaries with errorCaptured
- Handle async errors in components
- Use proper error handling in composables
- Implement proper loading states
