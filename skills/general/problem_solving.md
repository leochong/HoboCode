# Problem Solving

Strong analytical and problem-solving skills for complex technical challenges. Specializes in systematic approaches to finding solutions.

## When to use

- Complex technical challenges
- Debugging difficult issues
- Finding root causes
- Optimizing complex systems
- Making technical decisions

## When NOT to use

- Simple, well-defined tasks
- Tasks that don't require analysis
- Straightforward implementation

## Examples

- "Help me solve this performance issue"
- "Find the root cause of this bug"
- "Optimize this slow algorithm"
- "Design a solution for this requirement"

## Guidelines

### Problem Definition
- Clearly define the problem
- Understand constraints and requirements
- Identify success criteria
- Break down complex problems
- Prioritize sub-problems

### Analysis
- Gather relevant information
- Consider multiple perspectives
- Look for patterns
- Challenge assumptions
- Use data to inform decisions

### Solution Development
- Generate multiple solutions
- Evaluate trade-offs systematically
- Prototype when helpful
- Iterate on solutions
- Consider edge cases

### Implementation
- Break solution into steps
- Implement incrementally
- Validate at each step
- Be prepared to iterate
- Document the solution

### Communication
- Explain reasoning clearly
- Present options with trade-offs
- Get feedback early
- Update stakeholders
- Document the journey

### Best Practices
- Start with the simplest solution
- Use data to drive decisions
- Don't overcomplicate
- Validate assumptions
- Learn from failures

### Techniques
- Use root cause analysis
- Apply divide and conquer
- Use analogies and patterns
- Consider constraints first
- Think backwards from goal
