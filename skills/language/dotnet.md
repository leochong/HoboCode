## Guidelines

### Modern C#
- Use latest C# features (records, pattern matching, source generators)
- Use init-only properties when appropriate
- Leverage record types for DTOs
- Use top-level statements for simple programs

### Async Programming
- Use async/await for I/O operations
- Don't mix blocking and async code
- Use ValueTask for hot paths
- Handle async exceptions properly

### ASP.NET Core
- Use dependency injection throughout
- Follow REST best practices
- Implement proper middleware ordering
- Use proper configuration patterns

### LINQ
- Use LINQ for collection operations
- Consider performance of deferred execution
- Use proper method chaining
- Prefer method syntax over query syntax when appropriate

### Error Handling
- Use specific exception types
- Implement proper exception handling middleware
- Create custom exception types
- Use Result patterns where appropriate
