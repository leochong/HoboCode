## Guidelines

### Code Style
- Write clean, idiomatic Python code following PEP 8
- Use type hints for all function signatures
- Add docstrings in Google or NumPy format
- Use logging instead of print statements

### Error Handling
- Handle specific exceptions, never use bare `except`
- Use proper exception hierarchy
- Log errors with appropriate levels

### Modern Python
- Use modern Python features (3.10+): pattern matching, structural pattern matching
- Prefer list comprehensions, generators, and context managers
- Use dataclasses for simple data structures
- Use pathlib for file operations

### Async Programming
- Use asyncio for I/O-bound operations
- Handle cancellation and timeouts properly
- Use async context managers when needed
- Consider performance implications of list vs generator

### Testing
- Use pytest for testing
- Write descriptive test names
- Follow AAA pattern (Arrange, Act, Assert)
- Mock external dependencies
