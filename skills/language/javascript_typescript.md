## Guidelines

### TypeScript
- Always enable strict TypeScript checking
- Avoid `any` type, use proper type definitions
- Use interfaces over types for extensibility
- Leverage generic types for reusable code

### Modern JavaScript
- Write modern ES6+ code
- Use async/await over raw promises
- Prefer const over let, avoid var
- Use template literals and destructuring

### Functional Patterns
- Use functional patterns and avoid side effects
- Prefer composition over inheritance
- Keep functions small and single-purpose
- Use proper module exports/imports

### Error Handling
- Use proper error handling with try/catch
- Implement error boundaries in React
- Create custom error classes when appropriate

### React Development
- Use functional components with hooks
- Implement proper state management (Context, Zustand, or Redux)
- Use proper effect cleanup in useEffect
- Optimize with React.memo when needed
